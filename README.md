# Task 6 - Sales Trend Analysis Using Aggregations

## Objective
Analyze monthly revenue and order volume using MySQL.

## Tools
- MySQL
- MySQL Workbench

## Analysis
- Monthly revenue using SUM()
- Monthly order volume using COUNT(DISTINCT order_id)
- Grouping by year and month
- Sorting monthly sales
- Finding top 3 months by revenue

## SQL Concepts Used
- SELECT
- SUM()
- COUNT(DISTINCT)
- GROUP BY
- ORDER BY
- LIMIT
- WHERE
- DATE_FORMAT()
